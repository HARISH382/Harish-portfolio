HARISH V — PORTFOLIO WEBSITE

Files:
- index.html: website content and sections
- style.css: responsive dark theme and layout
- script.js: mobile navigation behavior

HOW TO RUN:
1. Extract harish_portfolio.zip.
2. Open the extracted folder.
3. Double-click index.html to open it in your browser.
4. To edit content, open the files in VS Code.

IMPORTANT:
- Content is based on the uploaded resume.
- Verify the LinkedIn URL, GitHub profile, phone number, email, internship details, and project details before publishing.
- The resume did not provide a live demo or source-code URL for the project, so none has been invented.
- Google Fonts needs an internet connection; the website still works with fallback fonts offline.
